# Implementation

Task plans and their outputs. Design and architecture live in `specs/`.

- `2026-09-08-phase0-entity-count-proof.md` — the render-budget proof that
  briefs the rig proof commission.
- `results/` — benchmark output. Logs and test XML are gitignored: they are
  regenerated by re-running a script. The sweep CSVs are tracked, because they
  are not — reproducing one needs a particular physical device, off charge, for
  half an hour, and they are the measured evidence behind the render budget.
  Findings are still promoted into the plan document itself; the CSVs are the
  provenance behind them, not a substitute for reading them.
