# Broodline — Visual upgrade mockups v1

Status: visual direction approved on 2026-09-23. The user reviewed these concepts and said, “I like it.” Use this set as the visual reference for further work. These are generated visual targets, not screenshots of implemented Unity screens. Detail, silhouettes, modular traits, interaction and device performance still require production validation.

Created with the built-in image generation tool. The reveal includes a targeted correction to Ember’s parent portrait to restore its upright two-legged silhouette.

## Review focus

Character appeal, how close the rendering should be to Kingshot’s more simplified forms, environmental richness, ivory/violet UI, and text hierarchy. The small-view silhouettes and trait attachment details are concept-stage interpretations, not accepted changes to the gameplay model.
